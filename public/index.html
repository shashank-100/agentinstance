03 · Black box

Survives crashes.
Remembers everything.

Each agent lives in its own Durable Object with SQLite storage — one coordination atom, strongly consistent, always recoverable.

◉ Persistent memory

Full conversation history and state written to durable storage. Nothing is lost on eviction or crash.

⟲ Snapshots & restore

Best-effort recovery to the latest state. Outbound side-effects carry idempotency keys so a resumed agent never double-sends.

◷ Scheduled wakeups

Alarms let agents act autonomously on a timer — with a declared cadence, so stalled is never mistaken for idle.

⇄ Unified cross-channel history

One agent, one memory. It replies on the channel you messaged from, but the context is shared across all of them.

✈ Gate fees
Parking is free.

You only pay while an agent is actively working — model tokens plus compute seconds.
